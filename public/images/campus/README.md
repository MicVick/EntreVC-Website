# Campus photographs

Photographs of the IIM Ahmedabad old campus, used in the homepage gallery
(`components/public/campus-gallery.tsx`) and credited on each photo there. All come from
Wikimedia Commons under Creative Commons licences.

Changes to every file: resized and converted to WebP. Each is displayed with responsive CSS
cropping. Files adapted from a CC BY-SA original remain under that licence.
